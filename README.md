# Cartão Digital Interativo — Ingrid Vilela Beauty

Cartão digital *mobile-first* desenvolvido em HTML5, CSS3 e JavaScript puro para agendamento rápido via WhatsApp, acesso a localização, portfólio no Instagram e cópia de chave Pix.

## Estrutura de Arquivos

- `index.html`: Estrutura, estilos responsivos e interatividade do cartão digital.
- `logo.jpg` *(ou `logo.png`)*: Logotipo exibido no cabeçalho do perfil.

## Como Personalizar para o Cliente

No bloco `CONFIG` dentro da tag `<script>` do `index.html`, altere:

- `whatsapp`: número com DDI + DDD (`5571992246936`).
- `chavePix`: chave Pix configurada para o atendimento.
- `nomeSalao`: nome exibido nas mensagens automáticas do WhatsApp.
